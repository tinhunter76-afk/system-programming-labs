Анализ памяти и процессов.
Работа проводилась на виртуальной машине, в системе Ubuntu 24.04.3 LTS через терминал.

Согласно заданию выполнены действия:

1. Скомпилирована программа с динамическим выделением памяти.
2. Программа запущена и проверена её работа.
3. Выполнен анализ процесса с использованием:
   - ps
   - pmap
   - /proc/[PID]/maps
   - /proc/[PID]/status
   - valgrind
   - strace

Наблюдения:

- Программа использует динамическую память через malloc().
- Выделенная память располагается в heap-сегменте процесса.
- pmap показывает распределение виртуальной памяти:
  - code segment
  - heap
  - stack
  - shared libraries

- /proc/[PID]/maps содержит детальную карту памяти процесса.
- /proc/[PID]/status показывает:
  - размер виртуальной памяти
  - текущее состояние процесса
  - использование RAM

- valgrind подтвердил отсутствие утечек памяти.
- strace показал основные системные вызовы:
  - execve
  - mmap
  - write
  - exit_group

Вывод:

Динамическое выделение памяти работает корректно.
Память успешно освобождается через free(), утечки отсутствуют.
Инструменты Linux позволяют детально анализировать использование памяти и состояние процессов.
